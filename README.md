# 🤖 대학생 맞춤형 디스코드 비서 챗봇

> **학과 프로젝트 / 디스코드 파이썬 챗봇**  
> 수업 시간표 조회, 실시간 지하철 및 버스 대중교통 정보를 제공하는 대학생 맞춤형 봇 서비스입니다.

---

## 📌 주요 기능

| 기능 | 명령어 | 설명 |
| :--- | :--- | :--- |
| **시간표 조회** | `/시간표 [요일]` | 특정 요일의 시간표를 조회합니다. (미입력 시 **오늘 요일** 자동 조회) |
| **지하철 정보** | `/지하철 [탑승역] [하차역]` | 지하철 노선 및 도착 예정 정보를 조회합니다. |
| **버스 정보** | `/버스 [버스번호] [정류장]` | 버스 운행 및 도착 예정 정보를 조회합니다. |

---

## 🛠️ 기술 스택

- **Language:** Python 3.10+
- **Library:** `discord.py` (v2.0+), `python-dotenv`
- **Data Storage:** JSON (`timetable.json`)
