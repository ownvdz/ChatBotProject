국토교통부 TAGO API 통합 및
지하철 확장 아키텍처 구축

기존 버스 API 오류를 완벽히 해결하기 위해 국토교통부(TAGO) 표준 공공데이터 API로 표준화하였습니다. 더불어 실시간 버스 추적, 디버그 시스템, 학생용 시간표 기능, 그리고 인천2호선 지하철 확장 기반을 마련했습니다.

1. 버스 API 엔진 교체 (TAGO 공통 API)

높은 안정성 확보

국토교통부(`apis.data.go.kr/1613000`) 연동을 통해 기존 비표준 API의 데이터 유실 문제를 완전 해소

자동 재시도 로직

XML 파싱 및 일시적 응답 지연에 대비한 Retry 알고리즘 적용으로 정상 성공 코드(`00`) 검증 강화

단일 ServiceKey 모듈화

하나의 공공데이터 Key로 버스 및 지하철정보 서비스(`SubwayInfoService`)까지 확장 가능한 인프라 구축

2. 신규 및 고도화된 디스코드 명령어

사용자 핵심 기능

/버스 & /시간표

  • 511번 양방향 도착 안내: 주안역환승정류장 ↔ 정석항공과학고 실시간 잔여시간 계산
  • 차량번호 교차 추정: 실시간 위치 API 데이터를 비교 분석하여 운행 차량 식별
  • 개인화 시간표: `timetable.json` 연동을 통한 요일별 수업 시간/강의실 데이터 안내
개발 및 유지보수

진단 및 디버그 명령어

/버스디버그

nodeord, updowncd 순번 및 원본 파싱 확인

/정류소검색

키워드 기반 정류소 ID(nodeid) 실시간 조회

/버스위치

운행 중 511번 차량의 GPS 및 통과역 추적

/도시코드확인

인천 도시코드(23) 및 통신 상태 세션 검증
